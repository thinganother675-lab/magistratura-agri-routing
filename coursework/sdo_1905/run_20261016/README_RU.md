Рекомендация: не растягивать ради видимости. 16 октября 18:00–19:00 прочитать и при готовности сдать ПЗ-1–5; 17 октября 12:00–13:00 — ПЗ-6–10; 17 октября 17:00–18:00 — ПЗ-11–14 после личного повторения модели. Если всё понятно за один день, допустим вариант 16 октября 14:00–15:00 / 17:00–18:00 / 20:00–21:00 теми же блоками. Эти окна — предложение, не автоматизация и не совершённая отправка.

## Вариант для Дениса без выполнения работ

Рекомендуется тот же учебный кейс К01–К10 и вариант A — контролируемые файлы, шаблон, справочник и регламент. В исходной постановке нет обязательного распределения номерных вариантов по фамилиям: A и B допустимы. Варианты других дисциплин к этому курсу не переносятся. C исключён бюджетом и требованием сохранить APP-04. Собственный объект имеет смысл только при достаточных разрешённых обезличенных материалах; сейчас для этого нет необходимости.
