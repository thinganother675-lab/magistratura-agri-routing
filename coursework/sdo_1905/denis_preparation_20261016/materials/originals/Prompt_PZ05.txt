Выдай таблицу 6–8 шагов AS-IS и список связей для схемы: начало, конец, роль каждого действия, условие развилки. Отдельно выдай два изменения фрагмента процесса. УСЛОВИЯ — СИНТЕТИЧЕСКИЙ УЧЕБНЫЙ КЕЙС:
К02. Правила и результат работы
Каждой хозяйственной выдаче присваивается один код OP. Повторная пересылка той же выдачи не является новой выдачей. Код сообщения M обозначает отдельную доставку и может меняться при повторе; OP должен сохраняться.
В окончательный отчёт можно включать только подтверждённые записи с положительным числовым количеством в килограммах. Пустое значение не означает ноль. Разные количества для одного OP — конфликт; до уточнения обе записи исключаются из бесспорного итога и сохраняются для разбора.
Точного регламента разрешения конфликтов и замещения подтверждающего лица в текущем состоянии нет. Нельзя выбирать последнюю запись или усреднять количества без основания. Зафиксированный конфликт передают Р02; роль Р03 — выявить и показать расхождение.
Журнал источника за учебные сутки содержит семь кодов OP-101–OP-107. В выгрузку отчёта попало девять сообщений. Ожидается один отчёт со статусом «полный» либо «неполный», числом учтённых операций и перечнем нерешённых случаев. Бесспорный итог не равен расходу всего дня, пока остались нерешённые случаи.

К03. Текущее исполнение процесса
Р02 формирует потребность для группы. Р01 физически выдаёт корм и заносит OP, группу, корм и количество в локальный файл APP-01. Потребность и выдача — разные объекты; предварительный план не доказывает факт.
В конце смены Р01 передаёт файл в общую папку. Р02 отдельно отправляет подтверждение в сообщении APP-02. Р03 вручную сопоставляет подтверждения и строки и переносит их в APP-03. При неясности он связывается с Р01 и Р02.
При отсутствии ответа о получении Р01 может отправить файл повторно. APP-03 просто суммирует числовые количества из строк; автоматического контроля дублей, конфликтов и неподтверждённых строк нет. Р03 отправляет директору итог без автоматически рассчитанного признака полноты.
Для ПЗ описание этого порядка является фактом учебного кейса. Предлагаемые вами новые статусы, контроли, роли или сервисы нужно размещать отдельно в разделе «Предложение», а не приписывать текущей системе.

К04. Приложения и документы
APP-01 — локальный табличный файл склада: Р01 ведёт выдачи. APP-02 — существующий канал сообщений: Р02 направляет подтверждения. APP-03 — табличный файл бухгалтера: свод и итог. APP-04 — существующая бухгалтерская система, получающая итог после согласования; её внутренняя структура и API в кейсе не раскрыты.
DOC-01 — заявка/потребность; DOC-02 — запись выдачи; DOC-03 — подтверждение; DOC-04 — суточный отчёт. D01 — хозяйственная операция, D02 — корм, D03 — производственная группа, D04 — подтверждение. Приложение, документ и объект данных не являются синонимами.
Автоматизированных API-обменов в AS-IS не заявлено. Существование приложения не означает, что оно уже поддерживает желаемую функцию. Нельзя добавлять CRM, WMS или нейросеть только ради полноты перечня.

К08. Ограничения и целевые ориентиры
Проект должен сохранить APP-04. Разовые затраты в учебной оценке — не более 120 000 руб. Предполагаемый пилот ограничен складом С01 и одним отчётом. Нет задачи внедрить систему на реальном предприятии в рамках ПЗ.
Целевой ориентир активного времени подготовки — не более 40 минут на отчёт при сопоставимых условиях. Он ещё не измерен после внедрения. Правильность учёта и видимость неполноты важнее достижения скорости любой ценой.
Подтверждать выдачу должен не её автор. Предварительный отчёт должен показывать неполноту; окончательный — выпускаться только после разрешения существенных расхождений. Временное отсутствие связи не должно превращаться в сообщение «ничего не выдано».
Новые целевые RPO/RTO студент вправе предложить, но обязан назвать их проектными требованиями и указать способ проверки. Неизвестные величины AS-IS нельзя заменять придуманными измерениями.

КОМАНДА РЕМОНТА ОТВЕТА:
Не описывай ход выполнения. Верни сам результат по указанным колонкам: конкретные объекты, связи, числа, правила и основания. Фразы «получено», «передано», «всё проверено» без самого результата убери. Фактические результаты моего запуска не выдумывай.
