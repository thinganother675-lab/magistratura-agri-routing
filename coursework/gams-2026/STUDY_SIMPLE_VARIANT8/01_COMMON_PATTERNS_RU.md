# Общий шаблон трёх работ

Во всех трёх работах повторяется одна последовательность:

1. Перечислить объекты в Sets.
2. Записать известные числа в Parameters и Table.
3. Объявить неизвестные величины через Variable.
4. Объявить названия ограничений через Equations.
5. Записать формулы после двух точек.
6. Собрать Model и выполнить solve.
7. Посмотреть найденные значения .l.

## Индекс вместо отдельных переменных

```gams
Set j /milk,kefir,cream,skim/;
Positive Variable x(j);
```

j представляет набор названий. x(j) задаёт выпуск любого продукта из этого набора. GAMS сам создаёт четыре компонента x. Строки данных можно расширять; общий способ записи формулы сохраняется.

В третьей работе объектами являются фирмы. Там индексированный вектор lambda(j) задаёт веса эталонных фирм. Число эталонных весов определяется множеством j, а не количеством вручную написанных переменных.

## Таблица и её ячейка

```gams
a(r,j)
```

r выбирает строку, j выбирает столбец. Это одна ячейка матрицы. Например, a('rawmilk','cream') равна расходу сырья на центнер сметаны. Названия конкретных элементов записываются в одинарных кавычках. Буква j без кавычек обозначает перебор элементов множества.

## Сумма

```gams
sum(j,price(j)*x(j))
```

Для каждого продукта взять цену, умножить на выпуск и сложить. Скобки после sum содержат индекс, затем запятую и выражение. Знак * умножает числа.

## Семейство ограничений

```gams
resource(r).. sum(j,a(r,j)*x(j)) =l= capacity(r);
```

GAMS создаёт отдельную строку ограничения для каждого r. Две точки отделяют имя уравнения от формулы. =l= означает не больше. capacity(r) задаёт правую часть текущего ограничения.

В работах 8 и 10 формула другая по экономическому смыслу, но способ объявления и генерации строк такой же.

## Служебные знаки

| Запись | Смысл |
|---|---|
| `;` | Конец объявления или оператора |
| `,` | Разделение элементов или аргументов |
| `(j)` | Индекс объекта, а не умножение на j |
| `/.../` в объявлении | Начальные элементы или значения |
| `/` между числами | Деление |
| `*` между числами | Умножение |
| `s01*s20` внутри множества | Последовательность меток от s01 до s20 |
| `=` в присваивании | Записать вычисленное значение |
| `=e=` в уравнении | Равенство |
| `=l=` в уравнении | Меньше или равно |
| `=g=` в уравнении | Больше или равно |
| `.l` | Найденное или начальное значение переменной; буква L |
| `.lo` | Нижняя граница переменной |
| `<>` | Не равно в логической проверке |
| `$` | Применить присваивание или проверку при выполнении условия |

Десятичные числа в GAMS пишутся с точкой. Названия и код используют латиницу. Таблицы сохраняют выравнивание столбцов; при правке данных лучше заменять числа, не сдвигая заголовки.

## Повторение расчёта

```gams
loop(s,
    solve modelName using lp maximizing revenue;
);
```

loop повторяет содержимое для каждого элемента s. Перед solve можно подставить очередные условия, а после solve сохранить результат. Во второй работе повторяются сценарии и начальные точки; в третьей повторяются оцениваемые фирмы.

## Что смотреть после запуска

Сначала SOLVER STATUS, затем MODEL STATUS и LEVEL. Для LP ожидаются 1 и 1. Для нашей NLP в работе 8 нормальный результат имеет статусы 1 и 2: решатель сообщил локальный оптимум. Одиночная точка в таблице вывода GAMS обозначает ноль.

Количество строк данных само по себе не усложняет синтаксис: четыре строки коэффициентов или 25 строк фирм читаются по одному правилу. Сокращение числа разных конструкций полезнее, чем соединение многих команд в одну строку.
