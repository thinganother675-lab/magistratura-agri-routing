# Сначала прочитать

Учебные версии трёх работ для варианта 8. Прежние полные решения сохранены отдельно.

1. Начать с lab2/PATTERNS_RU.md и открыть lab2/OPEN_GAMS.cmd. Первая работа уже была короткой, её модель не изменена.
2. Прочитать 01_COMMON_PATTERNS_RU.md: множества, таблицы, переменные, ограничения, solve и .l повторяются в следующих работах.
3. Для второй работы открыть lab8/OPEN_GAMS.cmd. В одном lab8.gms находятся исходные данные, базовый расчёт и 20 сценариев, каждый с тремя начальными точками. Пояснения: lab8/PATTERNS_RU.md.
4. Для третьей работы открыть lab10/03_OPEN_GAMS.cmd. Пояснения: lab10/PATTERNS_RU.md. После решения запустить 04_RECALCULATE_STATS.cmd.

В GAMS Studio сохранить файл и нажать F9. В листинге .lst смотреть SOLVER STATUS, MODEL STATUS, значения LEVEL или итоговый DISPLAY. Для ЛР2 и ЛР10 нормальны статусы 1/1. Для нелинейной ЛР8 нормальны MODEL STATUS 2 и SOLVER STATUS 1.

Все три .gms самостоятельные, без include и комментариев. Полные числовые данные сохранены. В ЛР10 статистика выполняется отдельным скриптом tmp/gams-simple-tools/statistics_simple.py вне папок GAMS. Модель DEA решается в GAMS. Ярлыки рассчитаны на установленную программу и пути этого компьютера.

Проверки выполнены реальным GAMS: первая модель, 63 решения ЛР8 и 25 решений ЛР10. Результаты сопоставлены с полными версиями и независимыми проверками. Математические задачи не изменены ради сокращения кода.

Подробности сравнения и заключение отдельного ревьюера: 02_REVIEW_AND_COUNTS_RU.txt.
