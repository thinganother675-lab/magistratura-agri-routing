# ЛР10 вариант 8

Эта модель оценивает 25 фирм методом DEA с ориентацией на выпуск и переменной отдачей масштаба. Для каждой фирмы находится максимальный коэффициент роста обоих доходов phi при неизменных ресурсах. Эффективность равна 1/phi.

## Обозначения

| Символ | Значение |
| --- | --- |
| j | Все 25 фирм, которые могут образовать эталон |
| m | Оцениваемая фирма; второе имя того же множества через Alias |
| r | Показатели y1, y2, x1, x2 |
| outputs, inputs | Подмножества выпусков и ресурсов |
| data(j,r) | Таблица данных: доходы в тыс. руб., работники в людях |
| target(r) | Данные текущей оцениваемой фирмы |
| lambda(j) | Неотрицательные веса фирм в эталоне |
| phi | Коэффициент расширения выпусков, нижняя граница 1 |
| result(m,*) | Таблица результатов, включая оба статуса |

## Повторяющиеся приёмы

1. `Sets` и `Table` задают индексы и числовые данные. 25 строк таблицы повторяют один приём ввода, а не 25 разных моделей.
2. `Positive Variable` задаёт неотрицательные веса. `Variable phi` с `phi.lo = 1` ограничивает коэффициент снизу.
3. `sum(j, ...)` складывает ресурсы и выпуски эталонных фирм с весами lambda. `=l=`, `=g=`, `=e=` означают не больше, не меньше и равно.
4. `convexity` требует сумму весов 1. Именно это задаёт VRS.
5. `loop(m, ...)` повторяет один и тот же расчёт для всех фирм: выбрать target, решить LP, записать result.
6. `.l` возвращает найденное значение переменной. `.modelstat` и `.solvestat` возвращают статусы модели и решателя. Для этих запусков оба равны 1.
7. `File`, `put`, `putclose` сохраняют таблицы CSV; вложенный `loop(j, ...)` сохраняет все веса. Запись `:0:15` задаёт вывод числа с 15 знаками после точки. `.tl` выводит имя элемента множества.
8. `display result` показывает итоговую таблицу в листинге.

## Что упрощено

Удалены аварийные проверки `abort`, условный оператор `$`, логическая связка `or`, функции `max`, `abs`, `smax`, `smin`: семь конструкций. Удалены таблицы `used` и `weights`, диагностическая невязка внутри модели. В peers.csv выводятся все веса, включая нули, поэтому не требуется фильтр положительных весов.

Остались расчёт всех 25 фирм, статусы, исходные данные фактического запуска, веса эталонов и обе проверки Спирмена. Проверки выполняются снаружи, их Python находится в tmp/gams-simple-tools. Основная модель по-прежнему решается в GAMS.

## Порядок работы

1. Запустить `03_OPEN_GAMS.cmd`.
2. Изменить при необходимости данные, сохранить файл и нажать F9.
3. Дождаться окончания 25 решений и проверить статусы в result.
4. Запустить `04_RECALCULATE_STATS.cmd`. Он запускает внешний statistics_simple.py (46 строк) с данными именно этой папки.
5. Читать `02_ХОД_И_РЕЗУЛЬТАТЫ.txt`, `spearman.csv` и `COMPARISON.txt`.

GAMS экспортирует input_data.csv; статистика читает его, а не старую таблицу из assignments. Равным значениям назначаются средние ранги; шум эффективности около 1 устраняется перед ранжированием. Применяется двусторонняя перестановочная проверка при alpha = 0.05. Подробности p приведены в текстовом ходе решения.

Размер модели: 69 физических строк, из них 25 строк числовой таблицы; 44 строки без этих данных. Непустых строк 67, без данных 42. В GAMS нет строк комментариев.
