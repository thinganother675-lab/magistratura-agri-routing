ПОВТОРИТЬ ВСЕ РАСЧЁТЫ
Из PowerShell в этой папке:
  .\run_all.ps1
Это валидирует входы, решает независимые модели, запускает три GAMS-файла и сверяет результаты. При ошибке останавливается. Для повторного создания PDF:
  .\run_all.ps1 -BuildReports
Скрипт использует установленный здесь GAMS и bundled Python Codex, если он доступен; можно явно передать -PythonExe и -GamsExe.
На другом компьютере: установить официальный GAMS; установить Python 3.12, зависимости из requirements.txt; передать пути программ. Отчёты используют Windows-шрифты Arial и Consolas. Локальные дополнительные Python-пакеты находятся в runtime/python_packages.

ИЗМЕНИТЬ СЦЕНАРИИ №8
Открыть data/scenarios.csv. Разделитель - запятая; десятичный разделитель - точка. При сохранении из Excel проверить, что он не заменил разделитель на точку с запятой и не изменил названия колонок.
scenario_id - уникальное короткое имя латиницей с цифрами и подчёркиваниями.
raw_t - доступное сырьё, т/сут; mk_hours - часы первой общей линии; cy_hours - часы второй; p_milk/p_kefir/p_cream/p_yogurt - базовые цены при 100 т/сут, ₽/т.
Не менее 20 разных строк условий. Все цены/лимиты положительны; минимальный выпуск должен быть допустим. Прочие исходные коэффициенты фиксированы условием варианта и задаются в модели явно.
После редактирования запустить run_all.ps1. Отчёты автоматически не обновляются без -BuildReports. Архивы сдачи автоматически не обновляются: после изменений запустить scripts/package_results.py. Загрузить можно только комплект с успешной свежей проверкой.
Основной обязательный текстовый экспорт: results/lab8_scenarios_table.txt (UTF-8 TSV). Он содержит условия каждой строки, выпуски, целевую функцию и статус. CSV: results/lab8_final_scenarios.csv.
