# Sources and redistribution

New controlled scenarios are offered under CC0-1.0. AgXQA records are a deterministic subset of the authors' public Part B annotations from MSU-CECO/agxqa_benchmark_v1, pinned at commit 8626771b289d48cff113f0c13d0603ac644628c0. The repository has an Apache-2.0 LICENSE, downloaded alongside raw annotations. Embedded Extension source paragraphs may have their own underlying terms; a repository code license does not automatically resolve every source-document right. Verify those terms before publishing a redistributed data release. This project is transferred through a private repository for continued research; no public dataset release is made. The original Apache-2.0 license and pinned annotations are preserved in data/raw/agxqa/.

NASA POWER snapshot and attribution are recorded in data/raw/nasa_manifest.json. Consult the source service documentation for redistribution and provenance requirements. GGUF models and llama.cpp binaries retain their upstream licenses; they are excluded from Git. Other surveyed benchmarks were not downloaded or incorporated into this dataset.

Private worklogs, local credentials and unrelated project files are excluded from experiment prompts and repository artifacts. Results contain only public/synthetic task inputs and model outputs.
