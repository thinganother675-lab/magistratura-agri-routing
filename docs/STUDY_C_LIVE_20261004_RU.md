Это один заранее объявленный запуск на прежних 27 синтетических development cases. Он не является независимым подтверждающим тестом. Системы получают один public_request с открытым typed task, question, inputs и units; это не распознавание намерения из свободного языка. Model-only получает те же формулы и контракты. В инструментальном режиме модель возвращает JSON с ID инструмента и аргументами; приложение проверяет точное сохранение всего public inputs/units, JSON и allowlist, далее существующий детерминированный код проверяет контракт, полноту, единицы и диапазоны. Значения и отсутствующие аргументы не заполняются из gold или скрытых категорий. Результат исполнения возвращается модели для финализации. Это application JSON dispatch, а не native function calls. Явное уточнение модель может вернуть без исполнения.
