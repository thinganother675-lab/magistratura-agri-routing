## ILRI / CGIAR MELDATA: файл приобретен и проверен

[Официальная запись MELDATA](https://data.mel.cgiar.org/dataset.xhtml?persistentId=hdl:20.500.11766.1/FK2/6U4UAI) содержит **Question and Answer pairs with relevance to livestock-based agriculture in the Global South**, V4.0, выпуск 16.04.2026, CC BY 4.0. Сбор: хакатон ILRI в Найроби 09.06.2025; язык English. Репозиторий предлагает общий CSV 598 строк и его подмножество 312 заполненных ответов. Связанная публикация в metadata — новость CGIAR об AgriLLM, а не проверенная рецензируемая научная статья. Научная companion-публикация в этой проверке не установлена; новость, приложение Shiny/R и GitHub не входят в счет научных ссылок.

Корень задачи приобрел `ilri_metadata.json` и `ilri_all598.csv` из публичного официального сервиса; настоящий анализ прочитал эти файлы. CSV: 200 717 байт, SHA-256 `95ce974a5ccb7767a1054551011e8f1111b28bc87334d29ae46a5d0a0d13ae41`; MD5 `86389d50542d621da01d3f35517723dc` совпадает с контрольной суммой файла `114924` в официальном metadata. Сырые тексты находятся только в `.runtime/new_sources_20261003/`; в результатах аудита сохранены числа, идентификаторы строк, хеши и provenance.

`NA` — буквальный маркер пропуска, поэтому проверка только Python `not None` дает неверное число заполненных ответов/источников. Один sources содержит пустую строку; число 126 после исключения только NA тоже неверно. Полные распределения команд, персон и тем есть в manifest.

598 строк не равны 598 независимым задачам. Для предварительной консервативной группировки объединены одинаковые нормализованные вопросы, общие URL и одинаковые текстовые ссылки; все строки без источников помещены в общий bucket неизвестного происхождения. Получены **51 компонента**, крупнейшая содержит **540 строк**. Это сигнал для ручного разбора, а не оценка числа независимых документов: одинаковый URL может быть общей главной страницей, разные URL могут относиться к одному документу, а полностью одинаковые/переведенные/перефразированные задачи могут не выявляться простым сравнением. Весь набор дополнительно имеет общую группу события `ILRI_NAIROBI_HACKATHON_20250609`.

48 групп с разными ответами требуют экспертной adjudication: различие формулировок еще не доказывает ошибку, но не позволяет автоматически принять все ответы как один gold. Незакрытый вопрос или `NA` не является gold `ASK` либо `ABSTAIN`. Источник пригоден как новый кандидатный пул английских livestock-задач с provenance; русские пары, достаточность условий, границы безопасного ответа и качество ссылок еще не проверены человеком.

CC BY 4.0 установлена для депозита. Ссылка на внешний veterinary/government/other материал не дает права перелицензировать полный внешний текст. Перед выпуском отдельного evidence-пакета нужно проверить каждый сохраненный фрагмент, атрибуцию и upstream-права; до этого не включать полные чужие документы в открытый benchmark.

## Пересечение с историческими данными

Аудит сопоставил ILRI с историческим benchmark360 и его версией, bilingual DEV12, holdout150, raw AgXQA570, manifest источников holdout и ранее приобретенными официальными AgXQA splits **1503 / 353 / 330**. В объединении **2412 уникальных нормализованных вопроса и 80 URL**. Файлы и SHA-256 перечислены в manifest. Старый cache `agxqa_test.jsonl` содержит текст ошибки `Invalid rev id`, поэтому исключен как невалидный JSON; корректный `agxqa_test_main.jsonl` проверен. Исторический cache не исправлялся.

| Диагностический критерий ILRI против старых файлов | Найдено |
|---|---:|
| Точное совпадение вопроса после Unicode NFKC/casefold/нормализации слов | 0 |
| Word-set Jaccard ≥0.8 для вопросов минимум из пяти слов | 0 |
| Общие канонические URL в поле sources | 0 |

Результат означает только отсутствие совпадений по указанным правилам в указанных файлах. Он не доказывает отсутствие семантических, тематических, переводных повторов или попадания публичных источников в обучение модели. Общее происхождение документов требует ручной проверки. Старый FAO/AgXQA/NASA и использованные источники остаются исключенными из нового sealed holdout независимо от того, совпадает ли формулировка нового вопроса.

## Допуск в новый протокол

Ни один кандидат сейчас не является готовым sealed holdout. Для допуска необходимы идентификаторы исходных документов/событий и семей переводов, проверка прав на конкретный evidence, удаление пересечений со всем прежним DEV/holdout, независимая человеческая разметка ответа/действия и двуязычной эквивалентности, затем групповая фиксация DEV/holdout без настройки по holdout. Число независимых групп определяется после adjudication; 598, 29 982 или 51 нельзя подставлять в требование ≥120 независимых задач. Этот аудит не меняет статус нового протокола `DATA_BLOCKED` и не выдает публичные предварительные данные за финальную оценку.
