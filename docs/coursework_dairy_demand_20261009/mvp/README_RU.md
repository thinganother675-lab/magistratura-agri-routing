# Комплект Дениса. Вариант №6

Автор: Шестернин Денис. Группу добавить перед сдачей. Работа отдельная от варианта №3 Антония.

Для преподавателя: основной PDF с семью заданиями, расчётная таблица и презентация на два слайда. Тексты заданий сохранены отдельно для правок. Программа - дополнительная демонстрация, а не замена семи заданий. Закрепление темы проверить в итоговом списке старосты.

## Запуск демонстрации

Распаковать архив, открыть папку mvp и запустить в PowerShell: powershell -ExecutionPolicy Bypass -File .\start.ps1. Затем открыть http://127.0.0.1:8096/ . Окно сервера должно оставаться открытым. Закрытие останавливает сайт; отказ соединения означает, что сервер не работает. Адрес относится к этому компьютеру и не является опубликованным сайтом.

На компьютере Антония используется уже установленный Python Codex. На другом компьютере нужен Python 3 с NumPy: python -m pip install -r requirements.txt, затем python app.py --port 8096. Можно выбрать другой свободный порт. Ничего не устанавливается автоматически. Проверки: python -m unittest -v test_model.py.

В интерфейсе есть искусственная демонстрация, пример исходной таблицы, загрузка своего архива, план акций, семидневный прогноз, выпуск на завтра и экспорт. Для своего архива нужны не менее 180 последовательных дней по каждому представленному товару; для внедрения запрошены 24 месяца. Поддерживаемые коды: milk, kefir, yogurt. Поля: date,sku,sales,promo,stockout. sales - неотрицательное число упаковок; promo и stockout принимают 0 или 1. Возвраты ведутся отдельно. Пропуски и повторные даты отклоняются.

Сроки годности, мощность и запас задаёт пользователь. Реальные партии не загружаются автоматически. Прототип не составляет расписание всех линий и не запускает оборудование. Промышленная авторизация, журнал утверждения, интеграция с учётом и проверка свежести входят в будущий план.

## Просмотр и расчёт без сервера

В корне архива есть DairyPlan_offline.html. Его можно открыть двойным щелчком в обычном браузере. Страница содержит готовый прогноз на искусственных данных, выбор товара, выгрузку и проверку выпуска на завтра. Сервер, Python и интернет для этого просмотра не нужны. Новая таблица продаж в самой автономной странице не загружается.

Для нового расчёта без сайта открыть папку mvp и выполнить: python calculate.py --csv example_sales.csv --output results. Для искусственной демонстрации: python calculate.py. В results будут forecast.csv, forecast_report.json и offline.html. Программу можно запускать из другой рабочей папки, указывая путь к calculate.py и входному файлу.

Для полного сайта на Windows запустить start.cmd из папки mvp. Нужен Python 3.10 или новее с NumPy. Окно должно оставаться открытым; запуск открывает браузер автоматически. Если порт занят: powershell -ExecutionPolicy Bypass -File .\start.ps1 -Port 0. Программа напечатает выбранный свободный порт. Для запуска без автоматического открытия браузера добавить -NoBrowser.
