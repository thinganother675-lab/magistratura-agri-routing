# Продолжение работы на компьютере Дениса

Вариант №6: прогнозирование спроса на молочную продукцию для перерабатывающего предприятия. Автор - Шестернин Денис. Семь учебных заданий, расчётная таблица и два слайда подготовлены. Группа Дениса и закрепление темы пока неизвестны.

## Как начать

Распаковать архив в отдельную папку. Для готового просмотра открыть файл offline.html из папки mvp обычным браузером. Он содержит расчёт и работает без сервера. Для полного сайта запустить start.cmd в папке mvp и оставить окно открытым. Сайт открывается в браузере по адресу из окна. Если порт занят, выполнить в PowerShell: .\start.ps1 -Port 0. Если нет Python с NumPy, сначала установить зависимости по README_RU.md.

Для собственного архива без сайта: python calculate.py --csv example_sales.csv --output results. Для искусственной демонстрации: python calculate.py. В results появятся forecast.csv, forecast_report.json и автономная страница offline.html. Прогноз в автономной странице заранее рассчитан; выбор товара и проверка выпуска работают локально. Загрузка новых продаж и обучение в самой странице не выполняются.

## Что реализовано и что ещё можно добавить

Есть модель, проверка по датам, простой недельный эталон, загрузка продаж, план акций, прогноз, проверка мощности и годности, экспорт, автономный просмотр и расчёт из командной строки. Журнал подтверждений и промышленная авторизация отсутствуют. 9 октября сайт проверен в браузере на компьютере Антония: выбор товара, загрузка продаж, пересчёт по акции, просроченный остаток, ограничение мощности и выгрузка прогноза. Автономная страница проверена по содержимому и расчётам; открыть локальный файл встроенный браузер не разрешил. На компьютере Дениса запуск нужно проверить отдельно. Реальный архив, интеграция с учётом и производственный пилот требуют предприятия.

Главное перед сдачей - прочитать задания, указать группу, проверить закрепление темы и объяснять отличие точности модели от предполагаемой экономии. Для учебной защиты уже подготовленных документов достаточно как основы; автономная демонстрация дополняет их.
