## Тип работы, английский и moderation

Нужна завершённая самостоятельная эмпирическая статья с результатами, достоверными ограничениями и интересом исследователям. Moderation оценивает научную уместность/форму и **не является peer review**; даже accepted journal article не гарантирует приём. Существенная AI-помощь должна раскрываться, AI не включается в author list; каждый человек отвечает за весь текст, данные и ссылки. [Официальная moderation policy](https://info.arxiv.org/help/moderation/index.html).

Course project и proposal обычно не принимаются как тип материалов; происхождение работы из магистерского курса не освобождает от scholarly standards. Не достаточно назвать учебный draft empirical paper. Требуется реальный законченный вклад; узкий negative case study может быть научным вкладом, но принятие не обещается. [Content types](https://info.arxiv.org/help/policies/content-types.html).

Для отдельного CS review/survey/position paper с 31.10.2025 требуется принятие journal/conference и подтверждение успешно завершённого peer review; peer-reviewed journal reference/DOI указываются при наличии. Обычный workshop review недостаточен. Не применять эти ограничения ошибочно ко всем empirical research papers и не обходить их ложным переименованием обзора. [Официальное объявление](https://blog.arxiv.org/2025/10/31/attention-authors-updated-practice-for-review-articles-and-position-papers-in-arxiv-cs-category/).

В каждой submission нужен **полный английский текст**, а не только English abstract. В двуязычном файле английский идёт первым. [Текущие language правила](https://info.arxiv.org/help/faq/multilang.html). Русский учебный документ поэтому сам по себе не готовый arXiv package.

Возможное раскрытие для новой рабочей версии: «Generative AI assisted with code preparation, evidence organization, analysis support, drafting and translation. The human authors are responsible for verifying the claims, references, data rights and evaluation.» Пока human review не выполнен, не добавлять фразу «all outputs independently verified by authors». AI-generated gold/translation и авторское редактирование описываются фактически в Methods/Limitations.

## LICENSE OPTIONS — решение не принято

Официально доступны: **CC BY 4.0; CC BY-SA 4.0; CC BY-NC-SA 4.0; CC BY-NC-ND 4.0; arXiv.org perpetual non-exclusive license 1.0; CC0**. Лицензия каждой объявленной версии **необратима**; новый вариант не отзывает ранее выданные права. Кроме CC0, исходный copyright holder сохраняет ownership. [Официальные licenses](https://info.arxiv.org/help/license/index.html).

| Вариант для обсуждения авторами | Практическое значение |
|---|---|
| CC BY | Широкое reuse, адаптация/перевод и коммерческое использование с attribution; подходит open-science цели только при совместимости с выбранным издателем и правами на весь материал |
| arXiv non-exclusive | Даёт arXiv право постоянного распространения; не даёт читателям того же широкого права переработки, что CC BY. Рабочий кандидат при неизвестной издательской политике, но не гарантия совместимости |
| SA / NC / ND | Дополнительные ограничения; ND ограничивает распространение производных версий; выбирать лишь при понятной цели и проверке договора |
| CC0 | Отказ от контроля copyright/public-domain dedication; не соответствует выраженной задаче авторов сохранять обязательное attribution, автоматически не рекомендуется |

**Рекомендация:** сначала договор/политика русского venue, затем осознанный выбор обоих авторов между совместимыми вариантами; финального выбора здесь нет. Apache-2.0 программного кода не становится лицензией научной статьи, данных или provider outputs. Без нужных прав на сторонние figures/text нельзя компенсировать проблему выбором arXiv license.

## Sources/PDF и первый submission

Подаёт зарегистрированный человеческий author. Бесплатный workflow: согласовать manuscript/права → решить endorsement → выбрать категорию/лицензию → загрузить чистые файлы → проверить arXiv-generated PDF → metadata → финальное человеческое submit → moderation/announcement. В этой сессии workflow исследован, аккаунт не открывался. [Submission overview](https://info.arxiv.org/help/submit/index.html).

Если paper создан в LaTeX, arXiv требует **исходники**, а не один PDF от TeX. Нужны top-level .tex, используемые фигуры и custom styles/macros; для bibliography .bib/.bbl по текущему processor. Не добавлять backups, журнальные referee letters, лишние файлы или абсолютные локальные пути. Имена/регистр должны совпадать. [Официальные TeX правила](https://info.arxiv.org/help/submit_tex.html). Для PDF из другого authoring workflow применяются [PDF submission правила](https://info.arxiv.org/help/submit_pdf.html); ReportLab fallback не выдаётся за TeX compilation. Проверка локального PDF не доказывает успешную серверную компиляцию arXiv.

Технический gate для нашей новой версии: успешная фактическая компиляция; встроенные fonts; selectable text; понятные references; figures/tables/Unicode и PDF metadata; просмотр **всех** страниц; отдельный source archive только из необходимых файлов. Результат текущего tooling фиксирует lead-agent в build manifest. Здесь его успех заранее не объявляется.

Проверено новое ограничение: **до 2 новых submissions в календарный месяц и до 3 active**; replacements после v5 ограничены одним в неделю. [Текущая moderation policy](https://info.arxiv.org/help/moderation/index.html), [официальное объявление 01.10.2026](https://blog.arxiv.org/2026/10/01/updated-rate-limit-policy/). Непосредственно перед будущей подачей правила перепроверяются; нельзя расходовать slots пробной незавершённой статьёй.
