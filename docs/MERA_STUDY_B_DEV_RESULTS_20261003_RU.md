## Что нужно до большого запуска

1. Уточнить у MERA серверную метрику, версию и доступность индивидуальной
   правильности, права на публикацию результатов и описание каскада.
2. Утвердить людьми вопрос исследования, одну облачную модель, одну локальную,
   одно правило, статистические пределы и новый бюджет; затем заморозить код.
3. Проверить официальную упаковку и личный кабинет. Совместимый упаковщик
   тестируется на искусственных данных; приёмка настоящего архива не проверена.
4. Получить отдельное разрешение на внешнюю отправку; один раз выполнить
   выбранные политики на TEST без последующей настройки по его оценкам.

Планирование для 2642 TEST-заданий пока сценарное. CLOUD ONLY требует 2642
генерации; каскад — от 0 до 2642 дополнительных облачных генераций в зависимости
от правила. При 1000 входных и 256 выходных токенах на запрос и сохранённых
ценах Mercury это 1,167764 USD для CLOUD ONLY, до 2,335528 USD для двух
полных облачных ветвей. Линейный перенос среднего времени instant256 даёт
около 22,6 минут облачной генерации без загрузки, пауз и серверной оценки;
это не гарантия времени и не бюджет выбранной основной модели. После выбора
модели цена, токены, параметры и лимит должны быть пересчитаны до вызовов.
