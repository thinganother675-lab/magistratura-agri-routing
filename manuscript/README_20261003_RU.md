## Поддерживаемая локальная компиляция

Встроенный редактор Codex повторно вернул `Unable to find standard directories for platform` для обеих новых TeX-версий. Отдельно используется официальный portable **Tectonic 0.17.0** Windows MSVC, без установки глобального TeX, изменения PATH, registry или других проектов. GNU binary был проверен по checksum, но не запустился из-за отсутствующей runtime DLL; MSVC binary успешно запустился. Проверены опубликованные SHA-256 архивов обоих вариантов. Зависимости TeX хранятся в ignored task-local cache.

```powershell
.venv\Scripts\python.exe scripts\build_manuscripts_20261003.py
$env:TECTONIC_CACHE_DIR = Join-Path (Get-Location) '.runtime\tex20261003\cache'
& .runtime\tex20261003\tectonic-msvc.exe --keep-logs manuscript\russian_routing_20261003.tex
& .runtime\tex20261003\tectonic-msvc.exe --keep-logs manuscript\english_routing_20261003.tex
```

Русскому TeX нужны Times New Roman, Arial и Consolas, доступные в проверенной Windows-среде. Переносимость этих шрифтов на другой ОС не проверена; не распространять proprietary font files. Английский источник использует стандартные LaTeX fonts/packages, внешних изображений или `.bib` не требует. Повторная локальная компиляция чисто распакованного English source archive проверяется отдельно; arXiv server compilation остаётся **UNVERIFIED**.

QA-script `scripts/compile_manuscripts_20261003.py` требует Tectonic и Python с `pypdf`, `pypdfium2`, Pillow. В текущем Codex это bundled artifact runtime; пути runtime являются свойством среды, а не обязательным private dependency статьи. Скрипт проверяет embedded fonts, selectable Unicode text, имена, основные числа, 18 ссылок, статус DATA_BLOCKED, historical hashes, рендерит каждую страницу и создаёт контактные листы. Итоговые логи и metadata: `results/publication_build_20261003/`; page renders: ignored `.cache/pdf_qa_20261003/`. Визуальная проверка выполняется человеком/агентом отдельно от автоматического счётчика.
